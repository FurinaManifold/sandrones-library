# 泛函分析标准序列空间 API 审计

- 审计基线：Mathlib 当前 checkout（Main `837e93f`）
- 权限：F2 concrete reflexive/nonreflexive examples `development_open`
- 结论：正例可直接开发；`c₀`、`ℓ¹`、`ℓ∞` 的经典对偶链尚不具备可直接挂靠的完整接口

## 可复用承载

- `lp E p` 已覆盖 `p = 1` 与 `p = ∞` 的序列空间承载、范数及完备性。
- `lp.dualPairing` 给出 Hölder 共轭指数下
  `lp E p →L[𝕜] lp F q →L[𝕜] H` 的自然配对。
- `ZeroAtInftyContinuousMap`（记号 `C₀(α, β)`）给出无穷远处趋零的连续函数空间；取离散
  `α = ℕ` 可作为经典 `c₀` 的现有候选承载。
- 典范双对偶嵌入仍直接采用 `NormedSpace.inclusionInDoubleDual`。

## 核心缺口

1. `lp.dualPairing` 当前只构造进入连续对偶的映射；没有在本次检索中发现一般的满射／等距等价，
   因而不能直接取得 `(ℓ¹)* ≃ ℓ∞` 或有限指数下 `(ℓp)* ≃ ℓq`。
2. `C₀(ℕ, ℝ)` 已有正确函数空间承载，但没有发现可直接复用的 `(c₀)* ≃ ℓ¹` 连续线性等距等价。
3. 没有发现 `c₀`、`ℓ¹`、`ℓ∞` 的已命名非自反性定理；也没有足以一行推出这些结论的
   非可分性／无限维实例链。

## 开发判断

- 不新增本地 `c0`、`l1`、`linfty` 类型或平行范数定义。
- 在 Main 另行开放“序列空间对偶识别”窗口前，只在教材文档把三者作为经典边界说明，不标记
  `verified`，也不以缺少接口为由复制 Mathlib 的 `lp` 或 `C₀` 基础设施。
- 若未来正式化，合理顺序是：离散 `C₀` 与趋零序列等价 → `c₀` 对偶识别 → `ℓ¹` 对偶识别 →
  由可分性或双对偶像的结构证明非自反性。该工作明显大于“定义讲清楚”的维护窗口。

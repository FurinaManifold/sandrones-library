## 论文究竟证明什么

论文 *Sur le principe de la condensation de singularités* 研究如何把不同算子列的异常行为
集中到同一个输入上。

- 定理 I：每行各有无界点，能找到令所有行同时无界的公共点。
- 定理 II：每行各有不收敛点，能找到令所有行同时不收敛的公共点。

原文的双数列用 `p` 标记行、`q` 标记列。
关键区别是把 `∀ p, ∃ x` 转成 `∃ x, ∀ p`；名字“Banach–Steinhaus”本身不能确定这个接口。
本次以 [库内论文 PDF](banach-steinhaus-1927.pdf)（[一手重印来源](https://kielich.amu.edu.pl/Stefan_Banach/pdf/oeuvres2/366.pdf)）
的 §2 定理 I、II（重印 pp. 369–370）为目标，定义见 p. 366，证明辅助引理见 pp. 367–368。
原文 §3 的正交级数应用另列后续批次。

## 从自然语言到可审核接口

| 原文中的选择 | 本次冻结的形式接口 |
|---|---|
| 连续实线性算子 | `E →L[ℝ] F p` |
| 完备定义域 | 实 Banach 空间 `E` |
| 不同行可有不同值域 | `F : ℕ → Type*`；行内固定 |
| 上极限无穷大 | 每个阈值、每个尾段都能找到更大的输出范数 |
| 不收敛 | 先证明非 Cauchy 版本；完备值域上转为“不存在极限” |
| 同一个公共点 | 点在行、阈值和尾段量词之前选定 |

这份约定同时解决定理名称的歧义和历史术语的歧义。
“值域不完备时无极限”与“非 Cauchy”没有被混用；完备性写在极限版定理的类型中。

## 实际证明工作流

```mermaid
flowchart LR
  A[读原文与冻结量词] --> B[六个接口的临时框架]
  B --> C[定理 I：开集与线性缩放]
  C --> D[Baire：公共无界点]
  D --> E[定理 II：有界／无界两分支]
  E --> F[联合接口与具体算子族]
  F --> G[公理、Entry 映射和提交]
```

本次由一个 Codex 实例串行执行阅读、接口设计、证明和检查，没有并发子 Agent。
第一批先让下层接口与上层存在性结论共同通过类型检查，再消除五个待证目标。
第二批同样先检查组装框架，再完成四个待证目标；正式模块中没有待证占位。

定理 I 的主要施工是证明每个阈值的超限点集稠密。
如果某个球内所有输出都受限，把已知坏点缩小后搬进这个球，线性就会把全局无界性与局部界
直接冲突。Baire 再把可数行、可数阈值的要求集中到同一个点。

定理 II 把每行分成两种情况。范数有界时，用三个 `ε/3` 误差证明 Cauchy 点集闭；
它是真子空间，补集开且稠密。范数无界时复用第一批公共无界点集。
两种分支都交付“坏点包含稠密 Gδ 集”的统一下层接口，最终组装只需 Baire。

## 验证结果如何阅读

增长算子 `Tq(x) = (q+1)x` 验证定理 I 的每个尾段无界。
交替符号算子 `Tq(x) = (-1)^q x` 的算子范数始终为 1，却在 `x=1` 处振荡，
验证定理 II 的有界分支及“不存在极限”的接口。
这些例子也由 Lean 证明，不是几项数值输出。

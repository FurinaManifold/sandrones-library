# 动机

"函数"是分析的载具，而**单射**（injective，一一对应地"不塌缩"）是函数的第一个重要性质。
当你组合两个函数时，一个自然的问题是：**单射性会不会被传递？**

这个问题的答案是"会"，而且证明极其干净。它给了你第一个"复合保持性质"的样板——
后面你会遇到一大族这样的定理（连续函数的复合连续、可导的复合可导…），
它们的证明骨架都和这一条一模一样：**逐层剥开**。

# 直觉

单射的意思是"不同的输入给出不同的输出"，或者说"函数不会把两样东西变成一样东西"。

复合 `g ∘ f`（先 f 后 g）如果塌缩了——`g(f(a)) = g(f(b))` 但 `a ≠ b`——
那塌缩只可能发生在 g 这一层或 f 这一层。但两层都不塌缩，所以复合也不塌缩。

形象一点：单射函数是"信息压缩的逆"——它可能压缩空间，但绝不合并两个不同的点。
两次不合并的压缩，合起来当然也不合并。

# 陈述（自然语言）

若 f : A → B 与 g : B → C 都是单射，则复合映射 g∘f : A → C 也是单射。
（即：若 `g(f(a)) = g(f(b))` 则 `a = b`。）

# 陈述（Lean 对照）

```lean
theorem injective_comp {α β γ : Type*} {f : α → β} {g : β → γ}
    (hf : Function.Injective f) (hg : Function.Injective g) :
    Function.Injective (g ∘ f)
```

| 人话 | Lean |
|---|---|
| f 是单射 | `hf : Function.Injective f` |
| g 是单射 | `hg : Function.Injective g` |
| 复合映射 | `g ∘ f` |
| 复合是单射 | `Function.Injective (g ∘ f)` |

# 思维脉络（thinking trace）

1. **展开目标**：`Function.Injective (g ∘ f)` 的定义是
   `∀ a b, (g∘f) a = (g∘f) b → a = b`。所以先 `intro a b h`。
2. **解析复合**：`(g∘f) a = (g∘f) b` 就是 `g (f a) = g (f b)`。
   这是 **g 收到的两个输入相等**。
3. **用 hg 剥一层**：g 是单射，输入相等 ⟹ 输出相等是对的方向。等等——方向要对：
   单射是"输出相等 ⟹ 输入相等"。这里已知 `g (f a) = g (f b)`（g 的输出相等），
   由 hg 得输入相等：`f a = f b`。
4. **用 hf 再剥一层**：`f a = f b` 是 f 的输出相等，由 hf 得 `a = b`。目标达成。
5. **为什么是"从外往里剥"**：复合是把两步动作串起来。等式从最外层 g 开始破，
   一层层往里，像剥洋葱。记住这个"从外到内"的方向，它贯穿整个数学
  （反函数、逆映射、同构的复合都这么证）。

# 自然语言 ↔ Lean 映射

| 人话 | Lean |
|---|---|
| f 的复合 g∘f | `g ∘ f` |
| 单射 | `Function.Injective f` |

| 剥洋葱 | 连续 `apply hf; apply hg` |

# 依赖（人话版）

无库内依赖。直接展开单射与复合的定义。

# 应用与陷阱

**应用**：
- 双射 = 单射 + 满射；双射的复合仍双射（由本条 + surj-comp 直接推出）。
- 定义域限制/嵌入：单射让你可以把 A 看成 B 的"子集"（A ≅ f[A]）。
- 后续：严格单调函数在区间上是单射（分析里用来保证反函数存在）。

**陷阱**：
- **方向陷阱（最经典）**：单射的定义是"输出相等 ⟹ 输入相等"，方向绝不能反。
  拿 g 用 `apply hg` 时，有人想成"输入相等推出输出相等"（那是函数的天然性质，
  不需要单射）而用错地方。
- **复合顺序陷阱**：`g ∘ f` 先算 f 后算 g。剥洋葱时要先剥 g 再剥 f，
  与书写顺序相反（最右的先执行）。
- **反过来不成立**：`g∘f` 单射推不出 g 单射（只有 f 一定单射）。这是后续条目的陷阱来源。

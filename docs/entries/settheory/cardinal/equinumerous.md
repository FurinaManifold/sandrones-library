# 定义

两个类型 `α`、`β` 等势，记作“`α` 与 `β` 有同样多的元素”，定义为二者之间存在双射：

```lean
def Equinumerous (α β : Type*) : Prop := Nonempty (α ≃ β)
```

双射同时要求单射和满射：不同的 `α` 元素不能撞到同一个 `β` 元素，并且每个 `β` 元素都必须
被配到。它给出两集合元素之间无遗漏、无重复的一一配对。

# 为什么不用“数出来”定义大小

有限集合可以先编号再比较元素个数，但无限集合无法靠数到最后。双射把“同样多”改写成结构问题：
只要能逐一配对，就认为大小相同。这一定义同时适用于有限集和无限集。

# 典型例子

- 自然数与偶数等势，配对 `n ↦ 2n`。偶数看似只是自然数的一部分，却与全体自然数同样多。
- 整数与自然数等势：可按 `0,1,-1,2,-2,…` 排列整数。
- 自然数与自然数平方 `ℕ×ℕ` 等势，可沿格点对角线枚举。
- 有限集合与其真子集不可能等势；无限集合则可能与真子集等势。

最后一点是无限集合与有限集合最显著的差别之一。

# 陈述（自然语言）

`Equinumerous α β` 等价于存在函数 `f : α → β`，它既单射又满射。

# 陈述（Lean 对照）

`equinumerous_iff_exists_bijective` 在打包的等价 `α ≃ β` 与普通函数加 `Bijective` 证明之间转换。

# 思维脉络

从等价映射到双射函数，只需忘掉逆函数但保留其单满射性质。反方向由双射函数构造逆函数，打包成
`Equiv.ofBijective`。本库公开定义使用教材概念，mathlib 的 `Equiv` 仅承载经过验证的双射数据。

# 自然语言 ↔ Lean 映射

- 等势 ↔ `Equinumerous α β`。
- 一一对应 ↔ `α ≃ β`。
- 单射且满射 ↔ `Function.Bijective f`。

# 应用与陷阱

- 存在任意函数完全不能说明两个集合一样大；必须是双射。
- “`α` 是 `β` 的真子集”不推出无限情形下严格更小。
- 等势只比较元素数量，不比较集合上的代数、拓扑或次序结构。

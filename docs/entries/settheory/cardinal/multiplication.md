# 从“每类各选一个”出发

有 `α` 类上衣和 `β` 类帽子，一套搭配需要同时选一件上衣和一顶帽子。单个结果不是左边或右边
的一项，而是一对 `(a,b)`。所有这种有序对组成笛卡尔积，因此乘法自然来自积类型。

# 定义

```lean
def CardinalProduct (α : Type u) (β : Type v) := α × β
```

于是 `|α|·|β|` 是 `α × β` 的大小。定义先给出具体对象——所有有序对——再谈这些对象有
多少个；没有直接把 mathlib 的基数乘号拿来充当解释。

# 有限乘法原理

若 `α` 有三项、`β` 有两项，对每个 `a` 都有两个可能的 `b`，所以一共有三组、每组两对，
即 `3·2=6`。这就是组合计数中的乘法原理。

若一边为空，就无法组成任何一对，因此 `0·κ=0`。若一边只有唯一元素，把 `(唯一元素,b)`
送到 `b` 即得双射，所以 `1·κ=κ`。

# 为什么有序对不能换成无序的“两元素集合”

乘法的两个位置有不同角色。`(上衣,帽子)` 与 `(帽子,上衣)` 甚至通常不属于同一个积类型；
即使 `α=β`，`(a,b)` 与 `(b,a)` 也一般是不同结果。无序二元集合会把它们错误合并。

# 无限网格的例子

`ℕ × ℕ` 是无限方格。虽然它看起来比一条自然数列宽得多，却仍可按对角线依次枚举，所以
`ℵ₀·ℵ₀=ℵ₀`。重点不是“网格等于直线”，而是网格点与自然数之间存在双射。

# 定义与代表无关

若 `e : α ≃ α'`，就在每一对的第一坐标应用 `e`，第二坐标不动：
`(a,b) ↦ (e(a),b)`。逆映射在第一坐标使用 `e⁻¹`。因此替换一个等势类型不会改变积的大小。
这由 `cardinalProduct_respects_equinumerous` 形式化。

# 自然语言 ↔ Lean

- 笛卡尔积 ↔ `α × β`。
- 一次成对选择 ↔ `(a,b)`。
- 在第一坐标搬运双射 ↔ `Equiv.prodCongr e (Equiv.refl β)`。

# 常见混淆

- 不交并中的元素只来自一边，积中的元素同时含两边坐标。
- 基数乘法只数有序对，不要求 `α`、`β` 自身具有数的乘法结构。
- `α × β` 与 `β × α` 的元素写法不同；交换律需要交换坐标的双射来证明，而不是定义上的相等。

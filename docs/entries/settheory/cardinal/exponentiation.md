# 指数在数什么

有限算术中，若每个位置都有 `m` 种填法，共有 `n` 个位置，那么完整填写方案有 `m^n` 种。
一个方案必须告诉我们每个位置选了什么，这恰好就是从“位置集合”到“可选值集合”的函数。

# 定义

```lean
def CardinalPower (α : Type u) (β : Type v) := β → α
```

因此 `|α|^|β|` 是全部函数 `β → α` 所成类型的大小。`α` 是底数，表示每个位置可取的值；
`β` 是指数，表示需要作出选择的位置。Lean 的箭头方向看起来与幂的书写次序相反，正是因为
函数写作“从位置到值”。

# 一个有限例子

两位二进制串共有四个。令 `β` 是两个位置，令 `α={0,1}`，每个函数 `β→α` 就是一种赋值：
`00,01,10,11`，所以 `2^2=4`。若有三个位置，就有八个函数，即 `2^3=8`。

# 零次幂与零的正次幂

从空类型到任意 `α` 只有一个函数：它没有输入需要处理，故 `|α|^0=1`。反过来，从非空
`β` 到空类型没有函数，因为任取一个输入都无法给出输出，故 `0^|β|=0`。`0^0=1` 在这里也
有清楚含义：空函数本身是唯一的函数。

# 幂集为何等于二的幂

一个子集 `S ⊆ β` 可以由特征函数记录：属于 `S` 的位置记为真，不属于的记为假。于是
`Set β` 与 `β → Bool` 等势，也就是 `|Set β|=2^|β|`。Cantor 定理因而告诉我们
`2^κ>κ`：全部二元选择模式永远无法由原集合自身完整编号。

# 无限序列例子

`ℕ → Bool` 的元素是无限二进制序列。与有限二进制串不同，它们不可数；对角线法能针对任何
声称的自然数枚举，逐位翻转第 `n` 条序列的第 `n` 位，制造一条遗漏的序列。

# 定义与代表无关

若 `α ≃ α'`，对函数 `f : β → α` 的每个输出应用该双射，就得到 `β → α'`；逐点应用逆映射
即可还原。因此等势的底数给出等势的函数空间。定理
`cardinalPower_respects_equinumerous` 形式化了这一事实。

# 自然语言 ↔ Lean

- `|α|^|β|` ↔ 函数空间 `β → α` 的大小。
- 一个完整选择方案 ↔ 一个函数 `f : β → α`。
- 幂集 ↔ 二值特征函数空间。
- 在所有输出上搬运双射 ↔ `Equiv.arrowCongr (Equiv.refl β) e`。

# 常见混淆

- `|α|^|β|` 对应 `β → α`，不能把函数方向写成 `α → β`。
- 函数不要求单射或满射；每一种赋值都要计入。
- 序数幂关注有序结构的递归，基数幂只计算函数总数；二者在无限情形中不是同一个运算。

# 动机

有理数稠密但可数。那么实数呢？Cantor 用一条惊世骇俗的**对角线论证**证明了：
**实数不可数**。这是数学史上"无穷有大小之分"的第一次铁证——
ℕ 和 ℝ 之间无法建立一对一的"点名"。

它的意义远超猎奇：连续统不可数，意味着"大多数实数没有名字"、
单调函数的不连续点至多可数因此"很少"、测度论里单点集测度为零的论证得以成立。
不可数性是分析大厦的一块基石。

# 直觉

假设你能把 [0,1) 里的实数列成一份"完整名单"：第 0 个、第 1 个、……。
现在**构造一个新数**：让它的第 n 位小数，故意与名单里第 n 个数的第 n 位小数不同。
这个新数不在任何一行（因为第 n 位就和第 n 行不同），却明明是个 [0,1) 的实数——
**矛盾**。所以名单不可能全，实数不可数。

# 陈述（自然语言）

实数集 ℝ 不是可数集。

# 思维脉络（thinking trace）

1. **否定可数**：要证 `¬ Countable ℝ`，假设可数——存在单射 f : ℝ → ℕ（countable-def）。
2. **名单的想法**：单射 f 给 ℝ 的每个元素一个号。反过来把实数按号排成一列
   `x₀, x₁, x₂, ...`（不要求满，可给"哑号"补齐）。
3. **对角线构造**：定义 d 使得 d 的每一位小数 dₙ ≠ xₙ 的第 n 位小数。
   d 是 [0,1) 里的数，所以 d = xₖ 对某个 k。但 d 的第 k 位 ≠ xₖ 的第 k 位——矛盾。
4. **矛盾收尾**：唯一的出路是承认"名单"不可能存在，即没有单射 ℝ → ℕ。
5. **形式化**：对角线论证展开成 Lean 证明相当长（要处理十进制展开的二义性，
   如 0.999... = 1.000...）。mathlib 把整套论证做成 `Uncountable ℝ` 实例，
   这里直接引用；数学构造细节在叙述层。

# 应用与陷阱

**应用**：
- "连续统不可数"是实分析的认知支柱。
- 单调函数至多可数不连续点：用不可数性 + 每个不连续点对应一个"跳跃间隔"，
  而"互不相交的开区间族至多可数"需要可数性论证。
- 测度论基础：单点为零测的推广。

**陷阱**：
- **对角线细节**：0.999... = 1.000... 的十进制二义性会让朴素对角线论证出错
  （构造出的 d 可能与名单里"看起来不同"的数是同一个）。形式化时要用
  Cantor 对二进制或规范展开处理。
- **思维陷阱**：对角线方法证明的是一类"不可穷举性"，但**不**适用于所有结构。
  可数集的对角线不产生新对象（因为这正是在构造一个没在名单里的元素，
  而它必须还在这个集合里——只有"名单真的全"才矛盾）。

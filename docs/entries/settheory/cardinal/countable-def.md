# 动机

"N 到底有多少个？"这是炽热的思辨问题，也是分析的基础。
可数性（countability）给出了"能逐个数过来"的形式定义，数学分析里处处用到：
可数个集合的并（级数理论）、有理数可数、实数不可数、单调函数的不连续点至多可数……

可数性的第一个基本事实，是它的**可操作刻画**：集合可数 ⟺ 存在到自然数的单射。
单射 = 一一编码 = 每个元素有唯一"编号"。这个刻画让"可数性"从抽象概念
变成了可以构造验证的性质。

# 直觉

"可数"就是"能被自然数点名"。单射 f 给每个元素分配一个不同的号码：
`f(a) = f(b)` 只可能是 `a = b`，所以没有两个元素抢同一个号。
号码有重复无所谓（数不齐时后面的号码可以用"),但每个元素必须有号且号不重。

# 陈述（自然语言）

集合 α 是可数的，当且仅当存在单射 f : α → ℕ。

# 陈述（Lean 对照）

```lean
theorem countable_iff_injective_nat (α : Type*) :
    Countable α ↔ ∃ f : α → ℕ, Function.Injective f
```

| 人话 | Lean |
|---|---|
| α 可数 | `Countable α`（mathlib 类型类） |
| 存在单射到 ℕ | `∃ f : α → ℕ, Function.Injective f` |
| 单射 | `Function.Injective f`（`f a = f b → a = b`） |

# 思维脉络（thinking trace）

1. **⇒（可数 ⟹ 有编号）**：可数集按定义能枚举成序列 `a₀, a₁, a₂, ...`，
   把第 n 个元素记号为 n，就得到单射。
2. **⇐（有编号 ⟹ 可数）**：单射 f 把 α 嵌入 ℕ 的像，按号码大小顺次列出即可。
3. **为什么"ℕ 是标尺"**：ℕ 是"最小的无穷"。一个集合可数，就是它能装进 ℕ 这个标尺
   （存在单射从 α 到 ℕ）。
4. **反过来想（不可数的定义）**：如果**不存在**这样的单射，集合就不可数——
   这是实数不可数（下一条目）的出发点。

# 自然语言 ↔ Lean 映射

| 人话 | Lean |

| 数得过来 / 可数 | `Countable α` |
| 逐个编号 | 单射 `f : α → ℕ` |

无库内依赖。

# 应用与陷阱

**应用**：
- 判定可数：构造单射到 ℕ（有理数 √ 自然数配对）。
- 判定不可数：证明没有单射到 ℕ（Cantor 对角线）。
- 级数、测度论中"可数个并"处理（见 countable-union）。

**陷阱**：
- **方向陷阱**：可数需要 α → ℕ 的单射（α 装进 ℕ）。反过来 ℕ → α 的单射只说明
  "α 至少有可数多个"，通常不够判可数。
- **思维陷阱**："可数"不等于"有限"。ℕ 自己可数但无穷。可数是"最温柔的无穷"。

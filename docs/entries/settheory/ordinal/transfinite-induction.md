# 动机
普通自然数归纳只处理后继；序数还含极限阶段，需要一次使用全部更小序数的结论。

# 直觉
若反例存在，序数良序性会给出最小反例；它的所有前驱都成立，与归纳步矛盾。

# 陈述（自然语言）
若对每个序数 `α`，从性质对所有 `β<α` 成立可推出其对 `α` 成立，则性质对所有序数成立。

# 陈述（Lean 对照）
`transfinite_induction {P} (step) : ∀ α, P α`。

# 思维脉络（thinking trace）
把序数严格序的良基归纳原则直接应用于任意 `α`。

# 自然语言 ↔ Lean 映射
| 人话 | Lean |
|---|---|
| 所有更小序数 | `∀ β < α, P β` |
| 良基归纳 | `WellFoundedLT.induction` |

# 依赖（人话版）
序数来自良序的序型，因此其严格序是良基的。

# 与普通数学归纳法有什么不同

自然数归纳通常写成“证明 `P(0)`，再证明 `P(n)→P(n+1)`”。这足够处理自然数，是因为每个
非零自然数都有直接前驱。但在序数中，`ω` 没有直接前驱：不存在某个最大的自然数 `n` 使
`n+1=ω`。因此只证明后继步骤，无法跨过第一个极限序数 `ω`。

超限归纳把归纳假设加强为：证明 `P(α)` 时，可以使用全部 `β<α` 上的结论。这一个形式同时
覆盖三种阶段：

- `α=0`：没有更小序数，归纳假设为空；
- `α=succ γ`：可以使用 `P(γ)`，也可使用所有更早结论；
- `α` 为极限序数：没有直接前驱，但可以使用所有 `β<α` 的结论。

# 最小反例证明

假设结论并非对所有序数成立，令 `C={α | ¬P(α)}`。由于序数严格序良基，非空的 `C` 有最小元
`α₀`。对所有 `β<α₀`，最小性保证 `P(β)` 成立。把这些结论送入 `step α₀`，得到 `P(α₀)`，
与 `α₀∈C` 矛盾。这就是 `WellFoundedLT.induction` 在内核中封装的数学论证。

# 应用与陷阱
- 极限序数没有“前一个”序数，不能只写自然数式的后继归纳。
- 归纳假设只允许用于严格更小的序数；对当前序数自身使用结论会形成循环论证。
- 超限归纳不是“归纳到某个无限数就结束”，而是覆盖全部序数的良基归纳原则。

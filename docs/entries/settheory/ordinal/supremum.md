# 动机
极限阶段通常把此前所有值取上确界。

# 直觉
对小指标族，若 `a` 已低于上确界，则必在某一项之前越过 `a`。

# 陈述（自然语言）
`a < sup_i f(i)` 当且仅当存在 `i` 使 `a<f(i)`。

# 陈述（Lean 对照）
`lt_supremum_iff {ι} [Small ι] f a`。

# 思维脉络（thinking trace）
直接使用序数上确界的共终性刻画；`Small` 控制宇宙大小。

# 自然语言 ↔ Lean 映射
| 人话 | Lean |
|---|---|
| 上确界 | `⨆ i, f i` |
| 小指标族 | `[Small ι]` |

# 依赖（人话版）
上确界是超限递归极限分支的标准组装方式。

# 序数上确界是什么

给定一族序数 `f(i)`，其上确界是同时不小于每个 `f(i)` 的最小序数。可直观地把它看成把所有
阶段积累起来形成的边界。例如有限序数族 `0,1,2,…` 的上确界是 `ω`：每个自然数都小于 `ω`，
而任何比 `ω` 更小的序数只是某个有限序数，不能支配全部自然数。

# 严格小于判据

等价式 `a < sup_i f(i) ↔ 存在 i，使 a < f(i)` 表达：上确界不会凭空跳出一个所有分量都
尚未越过的严格下界。若 `a` 已严格落在总上确界下面，族中必有某一项越过 `a`。这正是
“从下方共尾逼近”的形式。

`Small ι` 只是集合大小控制：索引族必须小到能在当前宇宙中形成序数，并非额外的数学有界条件。

# 应用与陷阱
- 省略 `Small` 可能造成宇宙层级不允许形成同一层的序数上确界。
- 上确界未必是族中的某一项；自然数族的上确界 `ω` 就不是任何有限项。
- 每项都严格小于 `a` 通常只能推出上确界不大于 `a`，未必仍严格小于 `a`。

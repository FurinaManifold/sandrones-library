# 动机

阶乘由 `0! = 1` 和 `(n+1)! = (n+1)n!` 决定：知道起点，再规定如何由前一项得到后一项，就能逐项算出整个函数。原始递归把这种熟悉的递推写法抽象成一个可复用的构造。

# 直觉

把计算想成一台只有“当前下标”和“上一轮结果”两个寄存器的机器。它从 `z` 出发，第 `n` 轮执行 `step n previous`。递归参数每次从 `n+1` 降到 `n`，所以一定在有限步后抵达零。

# 陈述（自然语言）

给定初值 `z` 与更新规则 `step`，定义函数 `f`：`f(0)=z`，且 `f(n+1)=step(n,f(n))`。例如固定 `a`，取初值 `a`、每步加一便得到 `a+n`；取初值 `1`、第 `n` 步乘 `n+1` 便得到阶乘。

# 陈述（Lean 对照）

`primitiveRecursion z step` 是本库公开定义。定理 `primitiveRecursion_zero_succ` 把零点和后继点两条计算规则合成一个合取；证明中的两个 `rfl` 表明它们直接由定义化简，而不是借用外部结论。`Nat.rec` 只登记为 Mathlib 中对应的递归原理，并未替代本库定义。

# 思维脉络（thinking trace）

先把所有具体递推中共同的“初值—更新”结构抽出；再让更新规则同时看见下标和旧值，以覆盖阶乘等依赖下标的例子；最后用自然数的结构递归保证定义良构。后续证明可对输入归纳，并在后继情形使用第二条计算式。

# 自然语言 ↔ Lean 映射

“初值”对应 `z : ℕ`；“第 n 步更新”对应 `step : ℕ → ℕ → ℕ`；“上一项”对应递归调用 `primitiveRecursion z step n`；两条操作语义对应 `primitiveRecursion_zero_succ` 的两个合取分量；`rfl` 表示等式两边展开后语法相同。

# 依赖（人话版）

数学上只依赖自然数有零和后继、并允许沿自然数递归。Lean 后端使用内核认可的结构递归；无需集合论、序数或基数理论。严格递归论中的“原始递归函数类”还包括零函数、后继、投影、复合与多参数递归，本条只建立最直观的一元骨架。

# 应用与陷阱

它可作为加法、阶乘和固定层超运算的递归模板。“递归定义”不自动等于“原始递归”，后者限制自调用形状；原始递归也不表示增长缓慢。Ackermann 的非原始递归性需要先形式化完整函数类和支配定理，不能从本条单独推出。

# 动机

在分析里你会反复处理"同时满足 A 且（B 或 C）"的条件。分配律告诉你这件事
等价于"(A 且 B) 或 (A 且 C)"——两个表达式看似不同，其实说的是同一件事。

它是"集合运算的顺序可以交换吗"这个问题的第一个答案：**交和并在同一个表达式中，
谁先算谁后算不是随便的**，但分配律给了精确的换序规则。类似的律还有并对交的分配律，
以及德摩根律（补集把交并互换并反转）。这些合起来构成集合代数。

# 直觉

集合恒等式是"穿着集合外衣的命题逻辑"。

- `∩` 对应逻辑"且"（and）
- `∪` 对应逻辑"或"（or）

所以 `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` 实质上就是命题逻辑的
**与对或的分配律** `P ∧ (Q ∨ R) ⇔ (P ∧ Q) ∨ (P ∧ R)`。
集合这一层没有新东西，直觉在逻辑层。

# 陈述（自然语言）

对任意集合 A、B、C：`A ∩ (B ∪ C)` 与 `(A ∩ B) ∪ (A ∩ C)` 相等。

# 陈述（Lean 对照）

```lean
theorem inter_distrib_left {α : Type*} (A B C : Set α) :
    A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
```

| 人话 | Lean |
|---|---|
| A 交（B 并 C） | `A ∩ (B ∪ C)` |
| (A 交 B) 并 (A 交 C) | `(A ∩ B) ∪ (A ∩ C)` |
| 相等 | `=`（目标，用 `ext` 展开） |

# 思维脉络（thinking trace）

1. **目标识别**：这是集合等式 → 第一反应用 `settheory.set.ext` 降到元素层
   （这正是外延性作为地基被调用的地方）。
2. **ext 之后**：目标变成 `∀ x, x ∈ A∩(B∪C) ↔ x ∈ (A∩B) ∪ (A∩C)`。
   固定一个 x，证双向。
3. **⇒ 方向**：`x ∈ A∩(B∪C)` 拆成 `x∈A` 且 `x∈B∪C`。
   `x∈B∪C` 分两支：`x∈B` 或 `x∈C`。
   - 若 `x∈B`，则 `x∈A∩B`，汇入左支。
   - 若 `x∈C`，则 `x∈A∩C`，汇入右支。
   这正是逻辑分配律的"或"分支展开。
4. **⇐ 方向**：`x ∈ (A∩B) ∪ (A∩C)` 分两支：
   - 左支给 `x∈A, x∈B` → `x∈A` 且 `x∈B∪C`。
   - 右支给 `x∈A, x∈C` → 同理。
   合并：`x∈A∩(B∪C)`。
5. **反思**：整个证明没有引入任何"集合特有"的推理——这正是要点。
   集合层的恒等式就是逻辑层的恒等式加一个 `ext`。

# 依赖（人话版）

- `settheory.set.ext`：外延性——把"集合相等"降到"逐元素双向属于"，
  这是所有集合恒等式证明的入口。

# 应用与陷阱

**应用**：
- 简化条件表达：`x ∈ A∩(B∪C)` 与 `x ∈ (A∩B)∪(A∩C)` 可互换。
- 德摩根律的证明套路与它完全相同（`ext` + 逻辑层），学会一个就会全部。
- 在测度论中，"可测集"的定义大量使用交、并、补的等式，分配律是基础工具。

**陷阱**：
- **换序幻觉**：`A ∩ B = B ∩ A`（交换律）成立，但 `∩` 与 `∪` 混用时不能想当然。
  分配律才是正确的换序依据。
- **方向陷阱**：分配律有左右两个版本（`∩` 对 `∪`、`∪` 对 `∩`），两者都成立但不等价于"结合律自由换序"。
- **逻辑层陷阱**：用 `rcases` 分或分支时，容易漏掉 `x∈A` 这一半。
  每支都必须同时保留"x 属于 A"的事实，否则回不去。

# 动机

商集（quotient）是"把一批等价的元素钉成一个点"的操作。它出现在数学的每个角落，
本库最直接的需求就是**实数构造**：把"互为极限差"的有理数柯西序列钉成同一个实数。

要使用商集，第一个必须搞清楚的性质就是：**商映射什么时候把两个元素送到同一个点？**
答案是：恰好当它们等价。这不是一条"顺带的定理"，而是商集的**定义性**性质——
它决定了商集真正做到了"合并等价类、保留不等价"。

# 直觉

商集上的元素 `⟦x⟧` 想表达的就是"x 所在的整个等价类"。
两个等价类重合 `⟦x⟧ = ⟦y⟧`，当且仅当 x 和 y 本来就等价（x ≈ y）。
等价就钉在一起，不等价就分开——商集不允许出现"该分开的却重合"。

# 陈述（自然语言）

对集合 X 上的等价关系 ≈，商元素 ⟦x⟧ 与 ⟦y⟧ 相等，当且仅当 x ≈ y。

# 陈述（Lean 对照）

```lean
theorem equivalence_class_eq {α : Type*} (s : Setoid α) (x y : α) :
    Quotient.mk s x = Quotient.mk s y ↔ s x y
```

| 人话 | Lean |
|---|---|
| 等价关系 ≈ | `s : Setoid α`，写成 `s x y` |
| 商映射 | `Quotient.mk s`，`⟦x⟧` 是记号 |
| 商值相等 | `Quotient.mk s x = Quotient.mk s y` |

# 思维脉络（thinking trace）

1. **不把它当定理，当定义**：`Quotient.eq` 是 Lean 商类型的**消元公理**——
   商类型就是这样"被规定的"。数学上这是商集构造的定义。
2. **读语义**：左式 `⟦x⟧ = ⟦y⟧` 是"两个商点重合"，右式 `x ≈ y` 是"两个底层元素等价"。
   它们互推，说明商操作**不多不少**：只合并等价的，不合并不等价的。
3. **为什么它对实数构造致命重要**：构造实数时，两个柯西序列定义同一个实数
   ⟺ 它们相差趋于 0（即等价）。这个性质保证"商出来的对象"确实按我们希望的规则相等。
4. **证明为 `exact Quotient.eq`**：因为这就是商类型的定义行为，没有更底层的证明可写。

无库内依赖（商类型的定义公理）。

# 应用与陷阱

**应用**：
- 实数构造（Cantor）：柯西序列的等价类。
- 群的陪集、环的理想商、向量空间的商空间（抽象代数阶段）。

**陷阱**：
- **方向陷阱**：`⟦x⟧ = ⟦y⟧ ↔ x ≈ y` 两边互为充要，别只记一边。
- **思维陷阱**：有人以为"⟦x⟧ 含有 x 附近的所有等价点所以可以≈"—错。商集把等价点合并了，
  一个等价类只有一个点，`⟦x⟧` 不是一个集合而是一个点（在商集里）。

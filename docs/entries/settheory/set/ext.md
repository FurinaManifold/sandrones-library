# 动机

数学分析的第一课是"集合语言"。但你写下的第一个符号 `A = B` 到底是什么含义？
如果有人问你"集合相等是什么意思"，最自然的回答是：**它们包含完全相同的元素**。

这个回答本身是一条原理——**外延性原理**（extensionality）。它说集合是"按元素决定的"：
一个集合没有比"由哪些元素组成"更多的信息。顺序、重复、内部结构都不重要
（`{1, 2}` 和 `{2, 1, 1}` 是同一个集合）。

它是集合论的公理之一，也是**所有集合恒等式的证明方法**：想证明两个集合相等，
永远可以退化为"任取一个元素，证明它属于左边当且仅当属于右边"。

# 直觉

**"集合相等"是一个可以逐元素核对的事实。**

把 `A = B` 想成一道闸门：`x ∈ A` 和 `x ∈ B` 必须始终同时开、同时关。
证明集合等式时，你不需要任何"集合层面"的花招——只需要检查元素层面。

这就是为什么数学里写"任取 x ∈ A，则……，故 x ∈ B；反之亦然"就证明了 `A = B`。

# 陈述（自然语言）

对任意集合 A、B：A = B 当且仅当对任意元素 x，x ∈ A 等价于 x ∈ B。

# 陈述（Lean 对照）

```lean
theorem set_ext {α : Type*} (A B : Set α) : A = B ↔ ∀ x : α, x ∈ A ↔ x ∈ B
```

| 人话 | Lean |
|---|---|
| 对任意集合 A、B | `(A B : Set α)` |
| A = B | `A = B` |
| 当且仅当 | `↔` |
| 对任意元素 x | `∀ x : α` |
| x 属于 A 等价于 x 属于 B | `x ∈ A ↔ x ∈ B` |

# 思维脉络（thinking trace）

1. **读目标**：一个双向蕴含 `(A = B) ↔ (∀ x, x∈A ↔ x∈B)`，所以要证两个方向。
2. **⇒ 方向（等式推出逐元素）**：若 `A = B`，则 `x ∈ A` 与 `x ∈ B` 是同一个命题——
   这正是"相等"的定义（Leibniz 律：相等的东西可以互相替换）。Lean 里 `subst h`
   做替换后，目标变成自反的 `x∈A ↔ x∈A`，`Iff.rfl` 收尾。
3. **⇐ 方向（逐元素推出等式）**：这就是外延公理本身。数学上我们"认为"它是对的
  （公理），Lean 里 mathlib 已经把它做成 `Set.ext`，直接调用。
4. **为什么这是地基**：后续每个集合恒等式（分配律、德摩根、并/交的结合律…）
   的证明都是"先 `ext x` 降到元素层，再做命题逻辑"。学会这一步，
   集合论一大半的证明都是机械劳动。

# 应用与陷阱

**应用**：
- 分配律、德摩根律、并交结合律等所有集合恒等式。
- 证明"两个集合的构造结果相同"（如证明像域、原像集的等式）。
- 商集、乘积集的定义合理性都隐含外延性。

**陷阱**：
- **方向陷阱**：`ext` 只适用于"等式"目标。目标是"包含 `A ⊆ B`"时，
  应展开为 `∀ x, x∈A → x∈B`（`Set.subset_def`），不是双向的。
- **思维陷阱**：有人试图"直接比较"集合内部——不存在这种事。集合没有内部结构可比较，
  只有元素。所有集合等式都在元素层证明。
- **记法陷阱**：`{1, 2}` 与 `{2, 1}` 是同一集合，但 `{1, 2}` 与 `(1, 2)`（有序对）完全不同。
  有序对是序列，集合不是。数学分析中"点 (x, y)"是乘积集中的元素，不是集合的集合。

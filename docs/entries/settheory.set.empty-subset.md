# 动机

空集 ∅（不含任何元素的集合）是集合论里第一个需要"勇气"接受的对象。
一个很怪的事实是：**∅ 是任何集合的子集**。空集里没有任何元素，凭什么它是别的集合的子集？

答案是：检查"∅ ⊆ A"时，我们不需要找到任何元素——因为根本没有元素需要检查。
这就是**空真（vacuous truth）**：形如"对所有 x，若 x ∈ ∅ 则 P(x)"的命题
因为前提永远不满足而自动为真。

# 直觉

"∀ x ∈ ∅, x ∈ A" 的意思是"不存在 x 破坏规则"。
空集里找不到任何破坏者，所以规则无人可破，命题成立。

就像面试条件"若有人在门口，请他进来"——门口没人，你也算执行了指令。

# 陈述（自然语言）

对任意集合 A，∅ ⊆ A。

# 陈述（Lean 对照）

```lean
theorem empty_subset {α : Type*} (A : Set α) : (∅ : Set α) ⊆ A
```

| 人话 | Lean |
|---|---|
| 空集 | `(∅ : Set α)` |
| 空集包含于 A | `∅ ⊆ A` |
| x ∈ ∅ 是假命题 | `hx : x ∈ ∅`（此时 hx : False） |

# 思维脉络（thinking trace）

1. **展开**：`∅ ⊆ A` = `∀ x, x ∈ ∅ → x ∈ A`。固定 x，得到 `hx : x ∈ ∅`。
2. **发现不可能**：`x ∈ ∅` 的定义就是 `False`（空集没有元素）。也就是说，假设本身就是矛盾。
3. **空真收尾**：从矛盾可以推出任何命题（`ex falso quodlibet`，Lean 里是 `False.elim`）。
   于是目标自动完成——不是我们证明了 `x ∈ A`，而是假设根本不成立。
4. **为什么这个证明"什么都没做"却是对的**：数学里 `∀x, False → P` 恒真，
   因为量词只在 x 使得前提成立时有义务。空集让这个义务集合为空。

# 自然语言 ↔ Lean 映射

| 人话 | Lean |
|---|---|
| 假设 x 属于空集 | `intro x hx` |
| 矛盾即真理 | `exact False.elim hx` |

无库内依赖。

# 应用与陷阱

**应用**：
- 证明 "∅ ⊆ A" 不需要任何前提，是每个集合都有的"平凡子集"。
- 空真原理贯穿分析：空集上的收敛、空集上的积分、定义域为空的函数等。

**陷阱**：
- **思维陷阱**：直觉上觉得"空集凭什么⊆别人"——要接受空真，别用"有元素"的直觉套。
- **方向陷阱**：`∅ ⊆ A` 恒真，但 `A ⊆ ∅` 只在 `A = ∅` 时成立。反了就错。

# 内容

本条目集中登记教材中反复使用的特殊值：
\[
e^0=1,\quad e^1=e,\quad \log 1=0,
\]
以及
\[
\sin 0=0,\quad \cos 0=1,\quad
\sin\frac\pi2=1,\quad \cos\frac\pi2=0,
\quad \sin\pi=0,\quad \cos\pi=-1.
\]

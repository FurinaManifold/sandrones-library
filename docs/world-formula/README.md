# 《水仙十字的世界式》

> 副标题：沿 Sandrone's Library 依赖路径展开的数学知识地图

这是 Sandrone's Library 的常驻自然语言书稿。它试图回答的不是“下一节课做哪道题”，而是：数学
世界中的对象为什么会出现，结构如何彼此变形，不同学科为什么会在同一个地方相遇。

本书可以很厚，也应当足够严谨；但它不是一套习题驱动教材。当前规划不提供足够的习题数量、难度
梯度、课程周次或完整解答，不能据此宣称适合独立授课。它更接近一部统一术语、路径和思想联系的
综合指南。

书稿正文采用纯自然语言与通常数学记号，不收录 Lean 代码、tactic 教程或 proof state。形式化资产
只负责核验事实，并在章末来源账中以 Entry id 定位；正文不能写成库接口说明书。

它也不是一部从头到尾板着脸的参考书。各章在适合闲谈、暴露误解或转换视角的位置加入原创的
提瓦特人物情景，让角色的观察方式帮助读者看见抽象结构。情景必须服务数学，并与正式定义、定理和
证明边界清楚分隔；具体规范见 [`TONE-AND-SCENES.md`](TONE-AND-SCENES.md)。

## 事实地位

本书自身不是数学事实源。各类文字按以下优先级解释：

1. **已验收事实**：Main 上的 Lean 源码、verified `index/registry.json` 与对应 Entry；
2. **出版背景**：`reference.bib` 中合规书籍或论文，但必须标明尚未形式化的部分；
3. **研究中的桥**：只可写成候选、障碍或开放问题；
4. **远期路线**：只来自 `docs/ROADMAP-LONGTERM.md`，不得使用完成语气。

当正文与这些来源冲突时，修正文稿，不修改来源来迁就叙事。

## 全书路线

全书按概念依赖而不是仓库目录的字母顺序组织。卷与卷之间允许回环，但任何阅读路线都必须说明其
前驱。

|---|---|---|---|

“主要库内路径”不是章节内容已完成的声明。每章只有在 ROADMAP 的 WF 批次接收后才进入正式目录。

## 章节目录约定

正式章节放在 [`chapters/`](chapters/README.md)，文件名采用两位卷号、两位章号和英文短名，例如：

```text
docs/world-formula/chapters/00-01-sets-and-maps.md
docs/world-formula/chapters/02-03-groups-and-symmetry.md
```

每章开头登记：状态、事实截止 Main commit、前驱章节、覆盖 Entry、出版来源和审稿记录。每章结尾
必须有“本章没有声称什么”和来源账。术语首次出现只在一个权威章节完整定义，其他章节通过链接
回指。

## 审稿

纯文本没有 Lean 编译器替作者拦截错误。所有章节必须执行
[`REVIEW-PROTOCOL.md`](REVIEW-PROTOCOL.md)：先做逐断言数学核验，再由不同审阅者做整体叙事、
术语、人物情景和出版编辑审核，最后由 Main 检查链接、事实截止点和跨章一致性。

# 《水仙十字的世界式》角色 ROLE 目录

人物情景不能凭作者对角色的模糊印象临场拼写。本目录为每个可能进入书稿的《原神》角色维护一份
独立 ROLE：它从米游社观测枢的角色故事、中文角色语音和相关剧情材料中归纳人物的判断方式与语言
边界，再把这些边界转化成可审核的创作约束。

## 四层资料结构

1. **原始缓存**：`scripts/fetch_miyoushe_wiki.py` 从观测枢官方 API 下载页面到
   `.cache/world-formula/miyoushe/`。缓存不进 Git，也不直接成为书稿正文。
2. **证据定位**：ROLE 记录 content id、栏目、语音标题或剧情页面，不大段复制原文。
3. **角色 ROLE**：归纳稳定人格、推理方式、语言节奏、关系动态、盲点和禁止写法；明确区分原文
   事实与编辑推断。
4. **书稿情景**：章节作者先选择适合该数学分歧的角色，再写原创场景；不得先挑角色标签，再让
   角色朗读定义。

米游社观测枢角色目录当前由官方 API 的“图鉴／角色”频道提供。角色页面的“角色展示”包含角色
故事和中文语音；任务或活动剧情若影响人物在特定时间点的状态，须另登记剧情页面及时间切片。

## 开发批次

- `CR0`：冻结抓取器、ROLE 模板、证据等级和审稿办法；
- `CR1`：覆盖第一章实际使用的纳西妲、砂糖、艾尔海森、卡维、莫娜；
- `CR2+`：按书稿章节需求逐地区扩展，最终覆盖观测枢目录中所有会进入情景的角色；
- 新角色随官方目录更新进入 `unprofiled`，没有 ROLE 前不得直接写进正式章节。

“已生成空文件”不算覆盖。一个 ROLE 只有在故事、语音、关系和剧情时间切片均完成独立复核后，才
能标为 `usable`。

## ROLE 文件

ROLE 放在 `roles/`，每个角色一个文件，并使用 [`ROLE-TEMPLATE.md`](ROLE-TEMPLATE.md)。章节
handoff 必须列出使用的角色 ROLE 及其版本；人物审阅者按 ROLE 而不是个人印象判定一致性。

# 提瓦特闲谈与人物情景写作规范

## 为什么需要人物情景

《水仙十字的世界式》不能只是一本换了书名的普通数学参考书。其他教材会在推导间隙讲历史、经验
或闲话，本书则可以在这些自然停顿处插入原创的提瓦特人物情景：让不同人物从各自的观察方式出发，
提出读者可能真正会问的问题，暴露一种常见误解，或把同一结构从另一学科重新看一遍。

情景必须承担明确的数学作用。例如：

- 对“两个对象何时算作相同”的分歧，引出等价关系和商；
- 从局部观察能否拼成整体的争论，引出局部—整体问题；
- 把有限情形的直觉贸然搬到无限情形，提醒读者寻找缺失的假设；
- 不同地区使用不同术语描述同一现象，帮助读者理解跨学科翻译。

如果删除一段情景后，数学理解、误区辨析和阅读节奏都毫无损失，它就只是角色贴纸，应当删去或
重写。

## 放在哪里

每章至少安排一个有数学功能的人物情景；长章通常可以安排二至四个。适合的位置包括：

1. 开篇提出本章问题；
2. 定义之后、读者最容易误解之处；
3. 定理之后，讨论它改变了什么、又没有解决什么；
4. 从一个学科转入另一个学科之处。

人物情景不得切断一个需要连续阅读的证明，也不得代替定义、定理、论证或来源。推荐采用以下醒目
格式：

```text
> 提瓦特闲谈：标题
>
> 原创情景正文……
>
> 数学作用：本段在说明……；它不构成证明。
```

“数学作用”可以写进情景后的正文，不必机械使用固定标签，但读者和审阅者必须能明确回答它是什么。

## 人物不是改名后的问答机器

- 人物的提问、判断和比喻应反映其观察方式、职业经验与性格，而不只是把“学生甲”“老师乙”换成
  角色名。
- 同一人物跨章出现时，应保持基本的认知立场；人物可以成长，但不能为了推进讲解而随意变换智力和
  性格。
- 不必复演游戏剧情。书中的短场景是服务数学讨论的原创侧写，不宣称是官方事件或被遗漏的任务。
- 不要让一个人物故意犯愚蠢错误，只为衬托另一个人物正确。应让错误来自真实、可理解的直觉。

## 数学与世界观的边界

提瓦特中的事物可以帮助形成直觉，却不能成为数学证据。

- 类比之后要说明它在哪一步停止适用；正式结论仍由数学定义与论证支持。
- 原作术语与数学术语仅仅同名或相似时，必须提醒读者不要混同。
- 不要强行为元素、命之座、地脉、七国等概念建立一一对应的数学体系。
- 人物可以说错，叙述者必须在附近指出错误及其修正，不能把误解留成悬案。

## 原创性与引用边界

书稿中的人物情景必须是新写的、具有转化性的同人内容。不得复制或近似改写游戏台词、任务文本、
角色故事、书籍和宣传文案，也不得用“官方设定证明了……”为数学断言背书。确需谈及某个原作概念
时，只作必要的简短概述和评论；数学事实来源仍只能是本库已验收资产或合规出版数学文献。

## 人物情景专项审查

审阅者逐段回答：

1. 这段情景服务哪个数学概念、误解或跨章联系？
2. 删除它会损失哪一种直觉或阅读节奏？
3. 类比在哪里失效，正文是否说清楚？
4. 人物的观点和说话方式是否前后一致？
5. 是否存在疑似照录、近似改写或伪造官方设定的内容？

前两问答不出来，情景应删除或重写；后三问存在实质问题，章节不得通过文字审核。
